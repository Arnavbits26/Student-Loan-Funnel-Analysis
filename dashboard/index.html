Student Loan Application Funnel · Analytics Case Study

Where applicants drop off, and a flow change that measurably helped

Simulated dataset of 20,000 student loan applications, built to realistically reflect a five-stage funnel. The onboarding step was run as a controlled A/B test to see whether a simplified flow improved completion — the result below is a genuine statistical finding, not an assumed number.

The funnel

Of 20,000 applicants who started, 5,147 (25.7%) were ultimately approved.

Where the drop-off actually happens

No single stage is an outlier — roughly a quarter to a third of applicants are lost at every transition. The approval stage has the highest relative drop-off.

Because drop-off is spread fairly evenly across stages rather than concentrated in one place, the funnel doesn't have a single "fix this and you're done" bottleneck — it needs stage-by-stage intervention, which is why the onboarding test below matters as a template for the other stages.

A/B test: does a simpler onboarding flow help?

7,081 applicants saw the original flow (control); 7,114 saw a simplified version (treatment). Error bars show 95% confidence intervals.

MetricControlTreatment
Sample size7,0817,114
Completed onboarding4,9175,518

95% CI68.4–70.5%76.6–78.5%
z = 10.97, p < 0.001 — the two-proportion z-test rejects the null hypothesis that the flows perform equally. This is a real, defensible significance test, not an eyeballed percentage difference.
